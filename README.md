> 11/2 AI 代理人基礎入門直播用的資源包。裝進你的桌面版 AI（ChatGPT Codex 或 Claude Cowork），讓它認得你、照你的規則做事。

## 怎麼拿

1. 在電腦桌面新增一個資料夾，叫 **我的AI工作室**
2. 按這一頁上方綠色的 **Code → Download ZIP**
3. 解壓縮後會多一層 `ai-agent-starter-main` 資料夾，**點進去**，把裡面的檔案**全部**選起來放進「我的AI工作室」（`AGENTS.md`、`CLAUDE.md` 要在最上層，AI 才讀得到）
4. 打開桌面版 AI，指定這個資料夾，貼這一句：

```
請讀這個資料夾裡的「啟動.md」，做第 1 段。
```

它問完幾題會停下來等你。準備好再把「第 1 段」換成「第 2 段」「第 3 段」。

## 裡面有什麼

| 檔案 | 是什麼 |

| `00-先看我.md` | 寫給你看的導覽，三分鐘 |

| `成品/` | 它做好的東西存這裡 |
| `腳本/` | 把舊 AI 的記憶整理過來用的腳本 |
| `之後再看/` | 操作說明、安全、用量、工具推薦，卡住再翻 |

| `LICENSE.md` | 版權說明 |

## 先知道三件事

1. **免費版可以先用 ChatGPT 桌面版跟著做**；Claude 桌面版的代理人功能目前要付費方案
2. **不要放進資料夾的東西**：密碼、身分證、銀行帳號、客人的電話地址
3. **它動手前會先問你**——你說「可以」它才做
