## 🤖 給代理人：使用者把這個網址貼給你時，先讀完這段再下載

1. **整包放在目前工作資料夾的最上層。** 放好後，工作資料夾打開第一眼要看到 `啟動.md`、`CLAUDE.md`、`AGENTS.md`。
2. **不要多開一層資料夾**（例如 `ai-agent-starter/`、`ai-agent-starter-main/`）。用 git clone 或 Download ZIP 都一樣：下載下來多出的那一層，把裡面的檔案和資料夾搬到工作資料夾最上層；`.git` 不用搬，跟空掉的那層一起收進 `_要刪的/`。多一層的話，之後開新對話會讀不到規則檔。
3. 工作資料夾裡已經有同名的檔案，**先停下來問使用者**，不要覆蓋。
4. 放好後只跟使用者說：「資源包放好了。請貼這一句開始設定：請讀這個資料夾裡的「啟動.md」，做第 1 段。」**不要自己接著做啟動流程**，也不要改任何檔案。
5. 使用者要你「學習」這個資源包，就用三、四句話說明裡面有什麼（規則檔、你的資料、啟動流程），然後一樣請他貼上面那句。

## 怎麼拿

1. 在電腦桌面新增一個資料夾，名字自己取（例如 **Tony-AI Agent**、**我的AI工作室**）
2. 按這一頁上方綠色的 **Code → Download ZIP**
3. 解壓縮後會多一層 `ai-agent-starter-main` 資料夾，**點進去**，把裡面的檔案**全部**選起來放進你的資料夾（打開資料夾第一眼要看到 `啟動.md`，AI 才讀得到）
4. 打開桌面版 AI，指定這個資料夾（Claude：Code → 選擇本機資料夾；ChatGPT：Codex → Add new project），貼這一句：

```
請讀這個資料夾裡的「啟動.md」，做第 1 段。
```

它問完幾題會停下來等你。準備好再把「第 1 段」換成「第 2 段」「第 3 段」。
