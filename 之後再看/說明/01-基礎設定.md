# 步驟 ①｜放好辦公桌：安裝、登入、指定資料夾

> 兩家選一家就好。**用免費版的話，請選 ChatGPT。**
> 畫面上的按鈕名稱，兩家都常常改版；找不到時，以官方說明為準（每段最後附網址）。
> 本說明依 2026-10-24 查到的官方說明寫成。

---

## 先選一家

| | ChatGPT 桌面版（Codex 模式） | Claude 桌面版（Cowork） |
|---|---|---|
| 免費版能不能用 | **可以**，用量比較少 | **不行**，要 Pro 以上的付費方案 |
| 規則檔叫什麼 | `AGENTS.md` | `CLAUDE.md` |
| Mac | macOS 14 以上 | macOS 13 以上 |
| Windows | 從 Microsoft Store 安裝 | Windows 10 以上；要有電腦的**系統管理員權限**，並開啟「虛擬機器平台」功能 |
| 下載 | chatgpt.com/download | claude.com/download |

> 想上 11 月的埔里實體課，需要訂閱 Claude Pro 或 ChatGPT Plus 其中一個（費用另計，依平台公告）。今天先用免費版感受看看也可以。

---

## A. 用 ChatGPT

1. **安裝並登入**：到 chatgpt.com/download 下載桌面版，用你的 ChatGPT 帳號登入（第一次用 Codex 時，可能會要你驗證手機號碼）
2. **切到 Codex 模式**：桌面版裡有 Chat、Work、Codex 幾種模式，選 **Codex**
3. **建資料夾、放資源包**：在桌面新增一個資料夾叫「我的AI工作室」；到資源包的 GitHub 頁面按綠色 **Code → Download ZIP**，解壓縮後把裡面的檔案全部放進「我的AI工作室」
4. **指定資料夾**：在 Codex 裡新增一個專案（Add new project），選「我的AI工作室」這個資料夾
5. **確認**：在對話框輸入下面這句，看它回什麼

```
請先讀這個資料夾裡的 AGENTS.md，用三句話告訴我你要遵守哪些規則。
```

它能說出「動手前先問你」「不知道就問、不要猜」「做好的東西存在成品資料夾」這類內容，就代表放好了。

官方說明：help.openai.com/en/articles/11369540（Codex 方案）、learn.chatgpt.com/docs/agent-configuration/agents-md（AGENTS.md）

---

## B. 用 Claude（需要 Pro 以上）

1. **安裝並登入**：到 claude.com/download 下載桌面版，登入你的 Claude 帳號
2. **切到 Cowork**：桌面版上方選 **Cowork**（新版介面可能已經跟聊天合在一起）
3. **把資料夾放到桌面**：同 ChatGPT 第 3 步
4. **指定資料夾**：在 Cowork 裡選擇本機資料夾，選「我的AI工作室」
5. **設定「資料夾指示」（Folder instructions）**：貼上下面這句，按儲存

```
每次開始工作前，先讀這個資料夾裡的 CLAUDE.md 和 我的資料.md，照裡面的規則做事。
```

6. **確認**：開一個新任務，輸入

```
請先讀這個資料夾裡的 CLAUDE.md，用三句話告訴我你要遵守哪些規則。
```

官方說明：support.claude.com/en/articles/13345190（Cowork 入門）、support.claude.com/en/articles/10065433（安裝與方案）

## 卡住了？
- 找不到 Codex／Cowork：先確認桌面版是最新版（重開 app 通常會自動更新）
- Windows 裝 Claude 失敗：多半是沒有系統管理員權限，公司電腦常見，請改用自己的電腦
- 其他問題：直播最後 Q&A 一起回答，或在 LINE @linket 問我們
