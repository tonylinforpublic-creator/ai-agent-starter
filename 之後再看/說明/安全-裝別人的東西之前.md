# 安全｜裝別人寫的東西之前

> 用一陣子之後，你一定會看到有人說「這個 skill 超好用」。這份教你怎麼判斷該不該裝。
> 大概 5 分鐘。**今天用不到，但遲早會用到**，先知道有這回事。

---

## 先搞懂一件事：skill 不是 app，是指令

網頁或手機上的 app，裝了之後它只能在自己的框框裡做事。

**skill 不一樣。skill 本質上就是一段寫給 AI 看的指令**——你裝了它，等於把一份「你要這樣做事」的紙條交給你的助理，而它會照做。

所以問題不是「這個 app 安不安全」，是：**我願不願意讓一個陌生人，幫我的助理寫工作守則？**

你不會隨便讓路人幫你的員工寫 SOP。skill 也是一樣。

---

## 你的規則已經幫你攔了

設定包的規則檔第 7 條寫著：

> 要裝別人寫的東西之前，先過三問。我說「幫我裝這個」的時候，你**不要直接裝**，先回答我三件事。

所以你什麼都不用記——**它會自己停下來問**。你只要看它的回答合不合理。

---

## 三問，和你該聽到什麼

### 問一｜這是誰寫的？

你想聽到的：有名有姓、找得到來源、有一些人在用。

⚠️ 警訊：找不到作者、剛發布沒幾天、沒人用過、網址看起來怪怪的。

### 問二｜它會動到我哪些檔案、連到哪裡去？

你想聽到的：只動工作資料夾裡的東西，不往外傳。

⚠️ 警訊：
- 要讀你資料夾**以外**的東西
- 會把內容**傳到某個網址**
- 要你的帳號密碼、API 金鑰
- 講不清楚、或講得很含糊

### 問三｜我現在真的需要它嗎？

你想聽到的：它解決你現在真的有的麻煩。

⚠️ 警訊：「看起來很厲害」「以後可能用得到」——**那就是還不需要**。

---

## 正確的說法

| ❌ 不要說 | ✅ 要說 |
|---|---|
| 幫我裝這個 | **幫我看這是什麼？適合我嗎？** |

差一句話，結果差很多。第一種是叫它執行，第二種是叫它判斷。

### 可以直接複製的審查提示詞

```
這是我看到別人推薦的東西：（貼上網址或內容）

先不要裝。請照我規則檔第 7 條回答我：
1. 這是誰寫的？找得到來源嗎？
2. 它會動到我哪些檔案？會不會把東西傳到外面？
3. 照我目前在做的事，我現在真的需要它嗎？

三個裡面有任何一個你答不清楚，直接跟我說「建議先不要裝」。
```

## 想更嚴謹一點（選配，有技術底子再看）

有公司做了專門掃 skill 的工具。最成熟的一個是 **NVIDIA 的 SkillSpector**：

- 網址：`github.com/NVIDIA/SkillSpector`
- 開源免費（Apache-2.0），2026-10-27 查為 22,400 顆星
- 它會掃一個 skill 的資料夾、壓縮檔或網址，回一個 0–100 的風險分數和建議
- 掃得到的東西：提示詞注入、偷偷外傳資料、要過多權限、相依套件有沒有已知漏洞

**但它要用 Docker 或 Python 跑，還要一組 API 金鑰**——以你現在的階段，這太重了。先用上面的三問就夠。

> 真的要用的時候，一樣先問你的助理：「幫我看 SkillSpector 怎麼裝、我這台電腦適合嗎？」

## 一句話記住

**別人的 skill 就像別人家的傢俱——不是好看就適合你家的格局。**

先問、再裝；用不到就不裝。你的助理會幫你守這條線。
