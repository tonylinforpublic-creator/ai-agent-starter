# 做完了嗎？用三句話測試

> **開一個全新的對話**（不要在剛剛訪談的那個對話裡測；要指定同一個資料夾——打開第一眼就看到 `啟動.md` 的那一個；指到上一層或開到一般聊天，它都會讀不到），依序貼下面三句。三句都過，你的 AI 辦公桌就放好了。

---

## 第 1 句：它記得你嗎？
```
我是誰？我是做什麼的？
```
✅ 過關：它照 `我的資料.md` 回答，不用你再講一次
❌ 沒過：它說不知道、說資料夾是空的、或從你的 email 猜你是誰 → 多半是資料夾指到上一層了，回 `01-基礎設定.md` 確認資料夾有指定好

## 第 2 句：它會照規則嗎？
```
幫我寫一則這週要發的訊息（有店的：優惠推播；上班的：給主管的週報開頭；還沒方向的：這週的待辦）。
```
✅ 過關：它**先問你**缺的細節（例如優惠內容、截止日、這週做了什麼），而不是自己編一個「全館 8 折」
❌ 沒過：它直接編了優惠 → 跟它說「請重讀規則檔的做事規則第 2 條」

## 第 3 句：它會存檔嗎？
（回答完它的問題之後）
```
可以，請存成檔案。
```
✅ 過關：`成品/` 資料夾裡多了一個「日期-內容」的檔案
❌ 沒過：它只在對話框裡貼文字 → 跟它說「請照規則第 3 條，存到 成品 資料夾」

---

三句都過了，恭喜你，接下來就可以讓它幫你做每天的事了。
