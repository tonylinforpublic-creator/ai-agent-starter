# 做完了嗎？用三句話測試

> **開一個全新的對話**（不要在剛剛訪談的那個對話裡測），依序貼下面三句。三句都過，你的 AI 辦公桌就放好了。

---

## 第 1 句：它記得你嗎？
```
我的品牌賣什麼？客人通常為什麼來？
```
✅ 過關：它照 `我的資料.md` 回答，不用你再講一次
❌ 沒過：它說不知道、或開始自己編 → 回 `01-基礎設定.md` 確認資料夾有指定好

## 第 2 句：它會照規則嗎？
```
幫我寫一則這個月的優惠活動 LINE 推播。
```
✅ 過關：它**先問你**優惠內容、價格、截止日（因為品牌資料裡沒寫），而不是自己編一個「全館 8 折」
❌ 沒過：它直接編了優惠 → 跟它說「請重讀 CLAUDE.md（或 AGENTS.md）的做事規則第 2 條」

## 第 3 句：它會存檔嗎？
（回答完它的問題之後）
```
可以，請存成檔案。
```
✅ 過關：`成品/` 資料夾裡多了一個「日期-LINE推播草稿」的檔案
❌ 沒過：它只在對話框裡貼文字 → 跟它說「請照規則第 3 條，存到 成品 資料夾」

---

三句都過了，恭喜你，接下來就可以讓它幫你做每天的事了。
