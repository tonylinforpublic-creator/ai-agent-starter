# 它的記憶怎麼管

> 這份是整包裡**最容易被忽略、但用久了最有感**的一份。大概 8 分鐘。
> 不用今天做完，用兩個禮拜之後再回來看，你會更懂。

---

## 它的記憶有三種，先分清楚

很多人以為 AI「記不記得」是一件事，其實是三件：

| | 是什麼 | 存在哪 | 誰決定 |
|---|---|---|---|
| **當下** | 這次對話裡講過的話 | 對話視窗 | — |
| **翻得到的** | 以前的聊天紀錄 | app 裡 | — |
| **真的記住的** | ①你寫的檔案　②它自己累積的筆記 | ①資料夾　②app 裡 | ①你　②它 |

第一種一關視窗就散了。第二種翻得到，但**它不會主動去翻**。

真正有用的是第三種，而且它分成兩半——**一半是你寫的，一半是它自己記的**。這兩半要分開管。

---

## 第一半：你寫的檔案（你說了算）

就是資料夾裡那兩份：

- **`我的資料.md`**——你是誰、賣什麼、客人是誰、語氣
- **`CLAUDE.md`／`AGENTS.md`**——你要它怎麼做事

**特性**：每次開工一定會讀、內容完全由你決定、你看得到也改得動、換電腦複製資料夾就帶著走。

> 這一半是「硬規定」。你寫什麼，它就照什麼。

### 怎麼維護

- 價格改了、搬家了、新增品項了 → **直接叫它改**：「品牌資料裡的營業時間改成…」
- 它做錯被你糾正 → 照規則第 8 條，它會問你要不要寫進規則
- 每隔一兩個月打開看一次，過期的刪掉

---

## 第二半：它自己累積的筆記（它說了算，但你管得動）

兩家的桌面版都會自己記一些東西——你糾正過它的、你的偏好、這個專案的慣例，它覺得值得留的會自己整理成筆記，下次遇到類似的事情拿出來用。

**特性**：它自己決定記什麼、是消化過的重點不是逐字紀錄、**預設綁在這個專案**（換資料夾、換電腦不一定跟著走）。

> 這一半是「經驗」。它會自己長，但也會長歪。

### 三件你該做的事

**① 看它記了什麼**

每隔一兩週問一次：

```
你目前記得關於我的哪些事？列給我看。
```

**② 把記錯的改掉**

```
第 3 點已經不對了，我們去年就改成…，請更新。
```

或直接叫它忘掉：

```
把關於「舊菜單」那幾筆刪掉，那些已經過期了。
```

**③ 重要的搬進檔案**

它自己記的東西，**換電腦、換專案不一定帶得走**。所以看到重要的，叫它寫進檔案：

```
這幾點很重要，幫我寫進 我的資料.md，不要只放在你的記憶裡。
```

> 💡 **判斷標準很簡單**：
> 「**這件事我希望它永遠照做**」→ 寫進檔案
> 「**這是它跟我合作累積的經驗**」→ 放它自己記就好

---

## 為什麼要管

不管的話會出現兩個問題：

**一、它拿舊的東西當現在的。** 你三個月前說過「夏天主打芒果」，它可能到冬天還在推芒果。

**二、你以為它記得，其實沒有。** 換一台電腦、或開一個新資料夾，它自己記的那半可能整個不見——這時候只有檔案那一半跟著你。

所以我的建議是：**重要的東西一律寫進檔案，不要只靠它記。**

---

## 每月五分鐘的保養

挑一個月初，問它這三句就好：

1. 「你目前記得關於我的哪些事？」
2. 「這裡面有哪些可能已經過期了？」
3. 「其中哪幾點你覺得應該寫進 `我的資料.md`？」

它會自己整理給你，你只要說要或不要。**整件事五分鐘。**
